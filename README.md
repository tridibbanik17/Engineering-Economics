# Facility Security Software – Engineering Economics Analysis

> **Course Project** | Engineering Economics | McMaster University
> Acting as a professional engineering consultant for the **Canadian Space Agency (CSA)** facility in Gatineau, QC.

---

## Project Overview

This project performs a comprehensive engineering economics analysis of a **Facility Security Software** subsystem designed to protect a CSA facility from data breaches and cybersecurity attacks over a **10-year project horizon**.

---

## Key Economic Results

| Metric | Value |
|---|---|
| Present Worth (PW) | $3,502,083.54 |
| Annual Worth (AW) | $498,617.91 |
| Internal Rate of Return (IRR) | 164% |
| Minimum Acceptable Rate of Return (MARR) | 10% |
| Nominal Annual Discount Rate | 7% |
| Project Horizon | 10 years |

**Conclusion:** IRR (164%) ≥ MARR (10%) → Project is economically viable.

## Repository Structure

### `Week2`
Documentation of the choice of subsystem, problem definition, objectives, constraints, key stakeholders, individual quantified design (design parameters and their justifications), conceptual system description, previous course to apply knowledge from, project Gantt chart.

### `Week3`
Risk management and uncertainty identification. Identified risks, likeliness of occurrence, frequency per year, mean time to happen, impact (low, medium, high), risk matrix with rows corresponding to probability and columns corresponding to impact, risk driver, uncertainty range, appropriate distribution (normal, lognormal, discrete, uniform), mitigation strategy, cost of implementation.

### `Week4`
Project management and cost benefit analysis. Work Breakdown Structure (WBS) assuming a 5-year project timeline assigning 4–6 major project phases and 2–4 tasks per phase, project scheduling and Critical Path Method (CPM) containing durations, dependencies, CPM network, identification of the critical path, screening-level cost benefit analysis summarizing total capital costs, total operating costs, total monetized benefits, the relationships between costs and benefits and project phases, interpretation of results at a planning level, alignment of assumptions across subsystems within the project team.

### `Outside_Project_CaseStudy`
From different co-op options, each with different costs and benefits, decided which option to choose by applying engineering economics concepts and justifying choice quantitatively.

### `Week6`
Economic evaluation of design alternatives. Comparing 2 designs for the same Facility Security Software subsystem by comparing their present worth and annual worth without accounting for inflation.

### `Week7`
Economic refinement and robustness analysis. Comparing 3 designs for the same Facility Security Software subsystem by comparing their present worth and annual worth after accounting for 2.4% annual inflation rate, determine the viability of each design by comparing each of their internal rate of return with minimum acceptable rate of return.

### `Week9`
Sensitivity analysis and uncertainty propagation. Sensitivity analysis using spider plot, created a stochastic model assigning randomness to stochastic terms, Monte Carlo simulation with 500 runs showing change in annual worth and present worth, identified mean, standard deviation, probability value > 0, confidence interval.

### `Week10`
Sensitivity analysis and uncertainty propagation. Sensitivity analysis using spider plot, created a stochastic model assigning randomness to stochastic terms, Monte Carlo simulation with 500 runs showing change in annual worth and present worth, identified mean, standard deviation, probability value > 0, confidence interval.

### `Week11`
Present and justify a design recommendation for the CSA facility, supported by technical reasoning, economic evaluation, and uncertainty analysis.

### `Week12`
Self-reflection of the project addressing project description, personal feelings, evaluation of experience, analysis of experience, conclusion.
